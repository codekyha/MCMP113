# MCMP113 – Introduction to Basic Algorithms and Programming

Lecture slides, lecture notes and example code for a 15-week introductory course on algorithms and programming with C# console applications (.NET 10, Visual Studio Code).

## Contents

Each `WeekNN/` folder contains the slides (`.pptx` and `.pdf`), the lecture notes (`MCMP113_WeekNN_Notes.pdf`) and, from Week 2 on, the example programs (`MCMP113_WeekNN_Code.zip`).

| Week | Topic |
|------|-------|
| 01 | Algorithms and problem solving |
| 02 | Flowcharts |
| 03 | Variables and data types |
| 04 | Operators |
| 05 | Decision structures |
| 06 | The for loop |
| 07 | While loops |
| 08 | Midterm review |
| 09 | Arrays |
| 10 | Array operations |
| 11 | Matrices |
| 12 | Functions |
| 13 | Return values and scope |
| 14 | Files and review |
| 15 | Final review |

## Running the examples

Install the [.NET SDK](https://dotnet.microsoft.com/download), unzip a code pack, then in any project folder run:

```
dotnet run
```
